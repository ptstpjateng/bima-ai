# BIMA-AI (Business Intelligent & Management Assistant) - Master Architecture

**Project Goal:**
Build an end-to-end AI assistant for DPMPTSP to unravel the bureaucracy of the OSS RBA for MSMEs. This is a Hackathon project scoped to demonstrate a complete flow from a messaging app to a post-licensing dashboard.

**The Three Pillars:**
1. Pre-Licensing (Smart Mapping): NLP via WhatsApp/Telegram to translate layman instructions into precise KBLI licensing guides and work as business assistant to guide all the things needed for licensing.
2. Licensing Execution (Integrated Navigation): A clean Next.js/React Native UI that simplifies complex OSS forms, savely store their licence data, help them fill anything needed for their specific license requirements.
3. Post-Licensing (Business Dashboard): A Super App ecosystem for operational management, finance, and market insights.

**Tech Stack (Hybrid):**
*   **AI Engine & Data Pipeline:** Python, FastAPI, LangChain/LlamaIndex, Vector DB (Chroma/FAISS).
*   **Core Backend & DPMPTSP Admin:** TALL Stack (Tailwind, Alpine, Laravel, Livewire) with Filament PHP.
*   **User-Facing Frontend:** Next.js (Web) and React Native (Mobile).
*   **Integrations:** Meta Cloud API (WhatsApp) and Telegram Bot API.

**Strict Coding Guidelines for All Agents:**
*   Every line of code must be highly secure, robust, and clean.
*   Implement the absolute best error handling (try/catch blocks, comprehensive logging, fallback UI states).
*   Prioritize a nice, clean, and clear UI/UX to minimize user cognitive load.
*   Work step-by-step and explain architectural decisions before executing bulk code generation.
