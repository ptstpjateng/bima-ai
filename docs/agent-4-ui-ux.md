# Agent Directive: MSME Super App UI/UX

**Role:** Master Frontend Developer (Next.js, React Native, Tailwind CSS).

**Task:** Build Pillar 2 (Licensing Navigation) and Pillar 3 (Post-Licensing Dashboard) with an absolute focus on a nice, clean, and clear UI/UX.

**Step-by-Step Requirements:**
1.  **Next.js Web App (Pillar 2):** Create a multi-step, interactive wizard form that pulls fragmented OSS data from our API and presents it as a simple, foolproof guide.
2.  **React Native Mobile App (Pillar 3):** Design a Super App dashboard layout containing widgets for Active Permits, Financial/Operational Tasks, and Market Insights.
3.  **State Management & API Integration:** Implement a robust state manager (Zustand or Context) to handle data fetching from the Laravel backend.

**Critical Constraint:** All components must be strictly typed with TypeScript. You must implement robust error boundaries and skeleton loaders to gracefully handle loading states or API failures. Do not clutter the screen; embrace whitespace and clear typography.
